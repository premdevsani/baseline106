DOM Structure

Understanding the Document Object Model of our website

What is the DOM?

The Document Object Model is a tree-like representation of every element on a web page

The DOM (Document Object Model) is a programming interface for web documents. It represents the page so that programs can change the document structure, style, and content. The DOM represents the document as a tree of nodes — every HTML tag becomes a node in this tree.

Below is the visual DOM structure of the Baseline website, showing how elements are nested inside one another, from the root <html> element down to individual components like navigation links, images, and text content.

Key DOM Concepts

Understanding the building blocks of web page structure

<html> — Root Element

The root node of the DOM tree. Every other element descends from it. Contains <head> and <body>.

<head> — Metadata

Contains metadata: character set, title, external stylesheets (CSS), fonts, and other non-visual resources.

<body> — Visible Content

Everything the user sees on the page lives here. Navigation, sections, images, text, forms, and the footer.

<nav> — Navigation

The consistent navigation bar present on all pages. Contains the logo, links (<ul> → <li> → <a>), and the mobile hamburger button.

<section> — Content Blocks

Thematic groupings of content. Each page uses multiple sections: hero banners, product grids, event timelines, contact forms, etc.

<footer> — Page Footer

The bottom of every page, containing brand info, quick links, contact details, and social media links.

Parent–Child Relationship

DOM nodes are related hierarchically. A <ul> is the parent of <li> elements, which are siblings to each other.

JavaScript & the DOM

JavaScript interacts with the DOM to create dynamic behavior — toggling menus, filtering products, validating forms, and running countdown timers.
